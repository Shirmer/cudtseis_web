# frp 通用部署示例

本目录提供架构示意和配置样例，不是生产环境的连接配置。真实服务器地址、端口分配、账户、成员公钥登记、主机指纹和运维记录应保存在团队私有文档中。

## 示例结构

- `frps.toml.example`：中转服务器配置；转发端口仅监听 loopback。
- `frpc.toml.example`：将本地 HTTP 服务通过隧道交给中转服务器反向代理。
- `frpc-ssh.toml.example`：仅通过 SSH 跳板访问的 SSH 隧道示例。
- [SSH.md](SSH.md)：通用客户端配置说明。

示例使用文档地址 `203.0.113.10`、示例转发端口及示例证书名称。实际部署前必须重新分配并核对所有参数，不能直接覆盖正在运行的服务。

## 部署原则

- 使用专用服务账户运行 frp，配置自动重启和适当资源限制。
- 控制端口只允许已确认的客户端来源，转发端口只绑定 `127.0.0.1`。
- 使用 TLS，并校验对端证书；认证令牌放在受限文件中。
- 令牌、TLS 私钥、SSH 私钥和真实配置不提交到公开仓库。
- 对配置做语法检查，并分别验证隧道、目标服务和外部入口。
- 维护记录、真实参数和回退方案由管理员通过内部渠道提供。

官方资料：[frp 文档](https://gofrp.org/en/docs/)、[frp 项目](https://github.com/fatedier/frp)。
