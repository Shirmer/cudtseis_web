# 成都理工大学地震研究中心官网

中文名称：成都理工大学地震研究中心；英文标识：Earthquake Research Center。

网站运行时为纯静态 HTML/CSS/JS，无后台、外部字体或 CDN 依赖。公共页面由 Python 标准库脚本在本地生成；学校服务器只需提供生成后的文件。公司官网源码继续独立维护。

## 页面结构

| 地址 | 内容 |
| --- | --- |
| `/` | 首页，展示近期成果与栏目摘要 |
| `/news/` | 新闻资讯总览 |
| `/research-bulletin/` | 科研快报，汇总三篇已提供的论文成果 |
| `/lab-news/` | 实验室快讯，面向学术交流、野外工作与团队活动；目前无已发布条目 |
| `/major-earthquakes/` | 大震信息，目前无已发布条目 |
| `/earthquake-science/` | 地震科普，包含公众号阅读入口与基础问答 |
| `/research-bulletin/文章名称/` | 论文简报全文、配图、参考文献与继续阅读入口 |
| `/catalog.html` | 独立地震目录，使用明确标注的虚构示例事件 |
| `/terra.html` | Terra 工具原型，预设示例输出，不调用计算服务或 AI 后端 |
| `/404.html` | 使用统一导航与页脚的错误页面 |

旧的三条根目录 `news-*.html` 地址保留，通过静态刷新跳转到新文章地址，同时提供可点击的正文链接。旧首页 `/#lab-news` 等锚点继续可用。微地震论文已与另外两篇论文统一归入“科研快报”；原文、图注、发布日期与研究结论保持不变。

## 编辑与本地预览

- `content/home.html`：首页内容与栏目摘要。
- `content/articles.json`：文章标题、日期、摘要、期刊、配图与旧地址。
- `content/articles/*.html`：各篇正文和参考文献；以老师提供的版本为准。
- `content/science.html`：科普文章入口与基础问答。
- `templates/header.html`、`templates/footer.html`：公共页面导航、中心标识与页脚。
- `scripts/build_site.py`：生成公共页面与旧地址兼容页。
- `assets/css/`、`assets/js/`、`assets/img/`：样式、交互和图片。工具页 HTML 单独维护，保持工作区结构。

在仓库根目录执行：

```sh
python3 lab-site/scripts/build_site.py
python3 lab-site/scripts/build_site.py --check
python3 -m http.server 4321 --directory lab-site
```

打开 <http://127.0.0.1:4321/>。所有网站链接以域名根目录为基准，部署时应将公开文件放在网站根目录。不要直接修改生成的首页、栏目页和文章页；修改内容或模板后重新生成。

导航由八个主要入口组成，四类资讯通过“新闻资讯”下拉菜单和栏目页切换。手机菜单分为了解中心、新闻资讯和数据工具。首页导航高亮随滚动位置更新；栏目与正文按页面归属高亮。

## 当前发布状态与部署

本轮栏目结构、首页布局与公共导航于 2026-11-04 发布，公开文件同步至学校服务器；发布验证和备份见部署记录。

- 网站文件位于学校服务器 `/srv/earthquake-center/current`，由独立 Nginx 容器提供服务。
- 临时入口访问链路：腾讯云 HTTPS → frp → 学校网站。腾讯云不保存实验室网站静态副本。
- 学校正式域名 `seis.cdut.edu.cn` 保持学校统一反代设计；公网入口状态见部署记录，不通过改 DNS 绕过学校反代。
- 配置、更新步骤和证书维护见 [网站部署说明](../deployment/websites/README.md) 与 [frp 说明](../deployment/frp/README.md)。

发布前重新生成并校验页面。只上传根目录公开 HTML、四类栏目及 `news/` 下的生成 HTML、`robots.txt` 和实际引用的 `assets/`。**不要上传 `content/`、`templates/`、`scripts/`、`docs/`、`design/`、README、Word 源文件或本地审阅产物。** 当前 Nginx 的目录首页配置可直接提供新栏目页，无需增加后台路由。

## 内容约束

主页观测图仍标注为示意图，标记图不是已核实的学校官方校徽，蓝色不是声称学校官方标准色号。人员按提供名单顺序仅展示姓名，暂不显示职务、职称和个人研究方向。不编造新闻、地震事件、联系邮箱或尚未提供的台站资料。

三篇简报采用提供的修订材料。日期是本站发布日期，不作为论文发表日期；第二篇韩奎团队简报 DOI 中多余空格已移除。新增文章时补充元数据、正文、图注、论文链接与图片，再重新生成。更新样式和脚本时修改构建脚本 `VERSION`，避免旧缓存。

## 微信公众号与工具原型

科普关联 **Geo Camera Group**，不是将其标为研究中心官方账号。当前文章为“寒露｜清露凝寒浸峻壑，层岩秋默对秋光”（2026-10-08），原文链接由用户提供。复制链接、复制名称及阅读二维码放在“更多阅读方式”中；阅读码仅编码该 HTTPS 文章地址，不是关注二维码。

后续科普采用官网版与微信版成对维护，取得官网版全文后再发布站内正文。公众号无凭证接入或自动采集，微信客户端“前往”跳转的实际行为取决于微信端。

目录与 Terra 仍是原型。笔记可在当前浏览器手动保存到 localStorage 并导出 Markdown；文件选择仅显示文件名，不读取或上传内容。历史功能盘点见 [历史功能清单](docs/functional-modules.md)。
