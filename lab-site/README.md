# 成都理工大学地震研究中心官网

中文名称：成都理工大学地震研究中心；英文标识：Earthquake Research Center。

独立的纯静态 HTML/CSS/JS 网站，无第三方依赖、构建步骤、外部字体或 CDN 请求，与公司官网源码分开维护。

## 页面与功能

- `index.html`：蓝白配色主页，包含中心概况、科研平台入口、科研快报、实验室快讯、大震信息、地震科普、成都理工大学地震台、研究方向、研究团队和联系信息。
- `catalog.html`：地震目录独立入口，支持示例事件筛选、选择与 CSV 导出；事件均为明确标注的虚构演示数据。
- `terra.html`：左侧多工具切换的 Terra 工作台，包含科研问答、波形、频谱、定位、文献检索、精读、翻译、笔记和报告草拟。分析输出为预设示例，不执行真实计算或调用 AI 后端。
- `news-microseismic-detection.html`：实验室快讯正文，按 2026-11-03 提供的修订简报发布，配两张研究图与论文 DOI。
- `404.html`、`robots.txt`：错误页面与搜索引擎访问规则。
- `assets/css/`、`assets/js/`、`assets/img/`：运行所需静态资源。

笔记可手动保存在当前浏览器 localStorage，并导出 Markdown。文件选择仅展示文件名，不读取或上传内容。科研快报已发布下地幔铁含量及氢增强晶界导电两篇成果简报；实验室快讯已发布微地震检测成果简报。大震信息继续使用空状态。

## 本地预览

在仓库根目录执行：

```sh
python3 -m http.server 4321 --directory lab-site
```

打开 <http://127.0.0.1:4321/>。入口链接均使用相对路径，可部署在不同域名的网站根目录。

## 内容维护

主页配图明确标注为示意图，标记图不是已核实的学校官方校徽。网页使用的蓝色为设计配色，并非声称学校官方标准色号。研究人员按提供名单顺序仅展示姓名，暂不显示职务、职称或个人研究方向。后续人员资料以学院正式资料为准；未公开未经确认的联系邮箱。

旧平台模块盘点保存在 [历史功能清单](docs/functional-modules.md)，仅供未来接入参考，不代表当前静态网站已提供这些后端能力。

## 发布实验室快讯

首页入口位于 `#lab-news`，完整正文为根目录独立 HTML，无须后台。新增文章时维护标题、发布日期、摘要、相对链接、完整正文、图注和参考文献。日期是本站发布日期，不作为论文发表日期。正文以提供的修订稿为准，不自行改写研究结果。文章页通过 `data-nav-section="lab-news"` 保持导航高亮。

更新必须包含首页、新正文、相关样式和图片，并在首页及新文章中更新 CSS/JS 查询版本号。Word 源文件、原始超大图片和审阅中间产物不上传公开网站。
